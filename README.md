# 🍽️ AI-Powered Canteen Management System

A smart canteen management platform developed using **Python, Flask, FastAPI, MySQL, and Scikit-Learn**. The system streamlines food ordering, inventory management, sales analytics, and leverages Machine Learning to predict food demand for efficient resource planning.

---

## 🚀 Features

* User Registration & Authentication
* Food Search & Ordering System
* Order Management
* Inventory Tracking
* Sales & Revenue Analytics
* Admin Dashboard
* AI-Based Food Demand Prediction
* RESTful API Integration using FastAPI
* Responsive User Interface

---

## ▶️ Installation

Clone the repository:

```bash
git clone https://github.com/your-username/canteen-management-system.git
```

Move into the project directory:

```bash
cd canteen-management-system
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

Open:

```text
http://127.0.0.1:5000
```
